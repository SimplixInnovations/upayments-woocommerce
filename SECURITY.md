# Security Policy

Payment integrations handle business-critical and potentially sensitive workflows. Security findings must be reported privately.

## Reporting a vulnerability

Do **not** open a public GitHub issue for a suspected vulnerability.

Report security-sensitive findings to:

**info@simplixi.com**

Use the subject: **[Security] UPayments WooCommerce**

Include only the information required to reproduce the issue. Do not send live API keys, bearer tokens, full card data, customer databases, or unnecessary personal information. If a secret is directly involved in the reproduction, describe its role and coordinate a secure method of exchange first.

## Useful report details

- affected plugin version or commit;
- WordPress, WooCommerce, and PHP versions;
- affected checkout mode;
- concise reproduction steps;
- security impact;
- whether authentication is required;
- minimal sanitized logs or stack traces;
- suggested remediation, if available.

## Disclosure

Please allow reasonable time for validation and remediation before public disclosure. Security advisories and release notes will avoid publishing operational details that would unnecessarily increase exploitation risk.
